# Official mascot reference

`original-stickers.png` is the official sticker sheet. What the in-game sprites are checked against:

- **Head:** a big white rounded triangle (an onigiri): wide rounded bottom, narrower top. About half the figure's height. Thin grey outline.
- **Red crystal:** a tall, faceted red crystal that **grows out of the crown**. Seen from the front it is a tall kite; **seen from behind** (the only view the game shows)
  it is a two-tone red wedge rising from the top of the head, its base hidden behind the head's outline. It is *not* a diamond laid over the head.
- **Face** (front view only): big dark eyes, pink cheeks, a small open smile. The game never shows it.
- **Body:** small and white, with a red neckerchief, a red cape, big round red mitts (fists), short legs and red boots.

The earlier sprites drew the crystal as a diamond laid on the head because they were derived from the old vector mascot in the game's code,
which had it that way. All four sets now draw the crystal as described above.
