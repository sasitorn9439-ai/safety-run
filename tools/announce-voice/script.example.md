# ตัวอย่างสคริปเสียงบรรยาย /announce (ข้อมูลตัวอย่าง ตัวเลขและผู้ชนะจริงจะถูกใส่ตอนรัน)

ผู้เล่น 64 คน · 54841 กม. · 600 ชม. · ผู้ชนะ 7 คน · gender=female

## s-cover.enter

- สวัสดีค่ะทุกคน
- ยินดีต้อนรับสู่การประกาศผลรางวัล Safety Run ในงาน EHS Day 2026ค่ะ
- ตลอดช่วงที่ผ่านมา ทุกคนได้วิ่งหลบอันตราย เก็บอุปกรณ์ PPE และตอบคำถามเซฟตี้กันอย่างสนุกสนาน
- วันนี้ถึงเวลาเฉลยแล้ว ว่าใครคือสุดยอดนักวิ่งทั้งเจ็ดคน
- แต่ก่อนอื่น ขอเล่าเกร็ดสนุก ๆ ให้ฟังสักนิดนะคะ
